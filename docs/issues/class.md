- **Recorder 6, fixed (review): `row:N` lit a table row and a reading together.** Now a reading lights only when the scene has no table or the table's `from` is the recorder's; otherwise `row:N` is the table's (case `recorder-table-good`, `out/c10/n5/recorder/probes.py`).
