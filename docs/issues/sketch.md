## Packaging and cold starts (2026-10-31)
- Sketch 42: **An offline page passes the 1 MB guide.** With `--katex-dir` the PCA page is 1,063 KB, against 435 KB with the CDN, and `check.py` does not warn. The limit is written for a page with the CDN. Either raise the limit for an inlined page, or make it warn.
- Sketch 43: **A leader line can vanish on navy.** On `pca-what`'s navy limits sheet the thin line from "CD19 is squashed flat" to its anchor is nearly the paper's colour. The contrast audit reads text, not leaders.
- Sketch 50: **`memory.py learner` records `skill: class` for a sketch page.** Line 111 of `class/scripts/memory.py` writes it for every caller. Seen on both cold starts. It needs a `--skill` option, and the user's OK.
- Sketch 54: **`make_data.py` can still type its numbers.** The lint reads `page.yaml` only, so a literal in the generator passes every gate. Run B's first page typed its rates and its read counts there. `verify_data.py` then agrees with a made-up value. No check catches this; only the judge's reading does.
- Sketch 56: **No check can catch a made-up quote in `sources.md`.** Run B round 2 quoted sentences that are in none of the three papers it named, and every gate passed. `SKILL.md` now says to copy words from a page opened in the run, but that is a prose rule. Only a judge opening the links catches this. Run B round 3 had that rule in hand and did it again: 3 of its Zheng quotes are not in the paper, it gives Zheng a 16 nt barcode (the paper says 14 bp), its PMC number does not exist, and `sources.md` holds no link. A check could fetch each link and search for the words, at the cost of a network step.
- Sketch 57: **Worked names with no `symbols` entry print as code.** Run A round 2 shows `aone`, `meanax`, `distanceA` on the page. A lint could warn when an `assemble` or `calc` name is longer than a letter or two and has no symbol.
- Sketch 58: **A plot can claim a difference it does not show.** Run B round 2 titled a sheet "PCR distorts" over two equal ratios, 4:2 and 2:1. `page.md` review question 6 now asks about this; no lint can.
- Sketch 59: **Home data can shape a topic badly.** The home table is genes by samples, so a droplet page relabelled samples as cells, and its hand count (2) did not match the matrix cell it pointed at (7). `page.md` review question 7 asks the agent to follow one worked number to the last table; nothing checks it.
- Sketch 60: **Open: a count of distinct things has no formula `assemble` can write, so agents make a circular one.** All three droplet runs did this: `r − d`, then `C = R/dup`, then `D = R/U` and `C = R/D`, which needs the answer U first. Review question 7 did not stop it. The lint demands an `assemble` on the formula beat, and that wants arithmetic. A `distinct` function, or a formula beat that takes a counting rule in words, would remove the pressure.
- Sketch 61: **Open: the `droplet` part cannot show two cells.** `state` is empty, bead or both. Run B round 3's sheet titled "Two cells in one droplet" draws one cell and a bead. The word "doublet" needs its own state.
- Sketch 62: **Open: Run B round 3 doc notes.** `page.md` does not say `row.<r>` sits at the table's right edge; the `read` part's anchors have no positions; a colon in a note needs quotes in YAML; `SKILL.md` step 8 shows `~/.viz-os/home/cells.json` where `$VIZOS_HOME` may be set; a `red` table mark on cream reads 1.8:1, and only the check says so.
